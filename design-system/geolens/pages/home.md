# Home / Marketing landing

> Overrides `design-system/geolens/MASTER.md` for `/` only.

**Pattern:** Semrush / Stitch AI Visibility — split hero, trust logos, capability trio, quote, alternating features, toolkit grid, social proof, CTA, footer.

## Rules

- Brand-first: **GeoLens** remains a hero-level signal above the outcome H1
- Eyebrow: `GeoLens AI visibility features` with teal mark (not purple)
- Hero CTAs: soft teal pill primary + outline secondary; black nav CTA
- Right column: Check visibility card (`AI visibility` kicker + outcome headline + domain input)
- Accent: GeoLens teal `#0f766e` — never Semrush/Stitch purple
- Font: Plus Jakarta Sans (display + body)
- Soft CTAs: text ≥ ~4.5:1 on soft fill; visible `:focus-visible`
- No fabricated review-platform scores (G2/Capterra) unless verified
- Trust logos: readable muted contrast (not ultra-faded)
- Motion: keep hero rise/slide; honor `prefers-reduced-motion`
- Mobile ≤960px: stack hero; hide dense nav links if needed

## Section order

1. Header  
2. Hero (copy + check card)  
3. Problem bridge + logos  
4. Solution trio  
5. Testimonial  
6. Deep features  
7. Toolkit grid  
8. Reviews / quotes  
9. Final CTA  
10. Footer

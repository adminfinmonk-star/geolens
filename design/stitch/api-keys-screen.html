Security Best Practices

do_not_disturb_on
Never commit keys to Git Store credentials in environment variables (GEOLENS_API_KEY) or secrets managers like Vault or AWS Secrets Manager.
sync
Rotate immediately on suspected leak If an API key is exposed in public logs or client-side bundles, revoke it immediately and create a fresh token. Revocation is instantaneous across all edge proxies.
lock
Enforce least-privilege scopes Grant only the explicit scopes needed by the machine agent. Avoid assigning root workspace admin permissions to background ingestion scripts.
timer
Recommended 90-day expiration Configure tokens to expire within 90 days. GeoLens will dispatch email alerts to workspace admins 14 days prior to expiration.

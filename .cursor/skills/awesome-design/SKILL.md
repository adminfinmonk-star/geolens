# Awesome Design MD

Local mirror of [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md).

## When to use

- Picking a visual direction for a new page or product surface
- Matching SaaS / marketing / dashboard patterns without inventing from scratch
- Auditing layout, typography, spacing, or component density against strong references

## How to use

1. Browse references under `.cursor/skills/awesome-design-md/design-md/`
2. Open the folder that best matches the product type (e.g. SaaS dashboard, landing)
3. Apply patterns to GeoLens with **existing brand tokens** (teal `#0F766E`, Plus Jakarta Sans, light theme) — do not copy purple/indigo “AI slop” palettes
4. Prefer structure + hierarchy from the reference; keep GeoLens CSS (`.geo-*`) conventions
